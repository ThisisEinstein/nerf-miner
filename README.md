# Nerf Miner

五分鐘一局的地下挖礦對戰遊戲。網頁版，可以**雙人連線對戰**，也可以單人對電腦（簡單／普通／困難）。

設計大綱：<https://claude.ai/artifact/JUKgeUedyjnYHiLuhoLUMN>

## 怎麼開始

1. 雙擊 `start.bat`。瀏覽器會自動打開遊戲；玩的時候不要關掉那個黑色視窗（它就是遊戲伺服器）。
2. 主選單選「雙人對戰」或「單人對電腦」。

需要 Node.js，不需要安裝其他套件。`start.bat` 會自己找 Node.js（PATH 或預設安裝位置）。

不要直接雙擊 `index.html`：瀏覽器不允許用這種方式載入遊戲程式，畫面上方會出現紅色提示。

## 雙人對戰怎麼連

1. 其中一個人開遊戲、選「雙人對戰」→「建立房間」，會拿到一個 4 位數房號和邀請連結。
2. 另一個人用下面其中一種方式進來：
   - **同一台電腦**：開一個新分頁，貼上邀請連結（`http://localhost:5173/?room=房號`）。
   - **同一個 Wi-Fi／區域網路的另一台電腦**：用瀏覽器開房間畫面上顯示的網址（像 `http://192.168.x.x:5173/?room=房號`）。黑色視窗啟動時也會印出這個網址。
3. 兩邊各選一個角色、都按「準備好了」，倒數 3 秒後開打。打完按「再來一局」可以直接續戰。

也可以按「快速配對」，和任何正在等人的玩家湊一桌。

注意事項：

- **防火牆**：第一次啟動時 Windows 可能會問要不要允許 Node.js 連網。要讓另一台電腦連進來就選允許；不允許的話只能在同一台電腦上用兩個分頁玩。
- **斷線**：對局中斷線或不小心重新整理，30 秒內回來可以接著打；超過就算輸。
- **延遲**：上方會顯示自己和對手的延遲（毫秒）。收不到伺服器的更新時畫面會停在最後的狀態並出現提示。
- **不同網路**（例如兩個人各自在家）：用下面「放到網路上」的線上版。
- 只想自己玩、不想讓區域網路的人連進來：用 `node server.js --local` 啟動。

## 放到網路上（Render）

專案裡的 `render.yaml` 是 Render 的設定。程式推到 GitHub 之後，在 Render 選 **New → Blueprint**、選這個 GitHub 專案，就會自動建好並給一個 `https://….onrender.com` 網址。之後每次推新的程式到 GitHub，Render 會自己重新部署。

免費方案的限制：

- 15 分鐘沒人連就會休眠，下一個人打開要等大約一分鐘才醒來。
- 主機的硬碟不會保留：重新部署、休眠或重新啟動之後，`data/accounts.json`（帳號與戰績）會被清空。要保留得改用付費方案並掛硬碟，然後把環境變數 `DATA_DIR` 設成硬碟的路徑。

在雲端時伺服器會：不顯示區域網路網址、用 `/healthz` 回報健康狀態、限制連線數（全部 400 條、同一個 IP 12 條，可用 `MAX_CONNS`、`MAX_CONNS_PER_IP` 調整），並把一秒內送超過 120 則訊息的連線斷掉。

對局是伺服器在跑的，每位玩家只會收到自己看得到的東西，所以打開瀏覽器的開發工具也看不到對手的家、陷阱或錢。

## 角色

進入對局前選一個，全隊得到一個小加成（數值在 `src/sim/chars.js`）：

| 角色 | 加成 |
| --- | --- |
| 老礦工 阿土 | 挖掘速度 +15% |
| 探險家 小光 | 礦工視野 +1 格 |
| 商人 金算盤 | 商店所有東西打 85 折 |
| 守衛 鐵柱 | 礦工血量 +1 |

## 帳號

在主選單或大廳按「登入 / 註冊」。登入後雙人對戰的勝敗會被記錄，並出現在大廳的排行榜；不登入也可以用訪客身分玩（可以自己取暱稱）。

- 帳號資料存在 `data/accounts.json`。密碼只存加鹽的 scrypt 雜湊，檔案裡沒有明碼。
- 區域網路的連線本身沒有加密（不是 https），所以請不要用你在其他網站用的密碼。
- 要清空所有帳號，關掉伺服器後刪掉 `data/accounts.json` 就可以。

## 操作

| 動作 | 方式 |
| --- | --- |
| 選礦工 | 點地圖上的礦工、下方卡片，或按 `1`–`5`、`Tab`；按住 `Shift` 再點可以多選，`F` 全選 |
| 指派任務 | 選好礦工後點地圖任何一格（或按右鍵），礦工會自己找路、挖過去、插火把 |
| 排隊 | 按住 `Shift` 點地圖：做完目前的任務再去下一個點（最多排 8 個） |
| 自動探索 | `G` 或卡片上的「自動」：礦工沒事做的時候自己找地方挖；手動下的指令優先；站在礦井或大寶藏上的礦工會等佔領完才走 |
| 找閒著的礦工 | `Q` 跳到下一個閒著的礦工；閒著的礦工卡片會閃、頭上有 zZ |
| 買道具 | 點右側商店；按**右鍵**是買了順便叫選取的礦工回家拿 |
| 拿道具 | 選好礦工後點「家裡的庫存」裡的道具，礦工會回家拿；`B` 是回家拿炸彈 |
| 用道具 | 按 `E` 進入瞄準，地圖上會標出作用範圍，點一下選位置，礦工會走過去自動使用；再按一次 `E` 在原地使用，`Esc` 取消。TNT 是用滑鼠選方向（炸彈不用按，走進敵方的家就爆） |
| 升級 / 回家 / 停下 | `U` / `H` / `X`（回家和停下會套用到所有選取的礦工） |
| 鏡頭 | 拖曳地圖、`WASD` 或方向鍵；滾輪縮放；點左上角的小地圖直接跳過去；`M` 大地圖；空白鍵回到礦工 |
| 聲音 | 右上角 🔊 開關音效、🎵 開關音樂 |

拿可以放置的道具（激光塔、尖刺、傳送門、假的家…）時，點完庫存會直接進入瞄準：先選好要放在哪，礦工回家拿了之後會自己走過去放。

## 規則數值

大綱裡寫「你自行判斷」的項目，目前定成下面這樣，都集中在 `src/sim/constants.js` 和 `src/sim/items.js`，改數字就能調平衡。

| 項目 | 數值 |
| --- | --- |
| 時間 | 每秒 10 個 tick，一局 5 分鐘 |
| 開局 | $60、3 名礦工、家裡一顆炸彈 |
| 收入 | 家 $1/秒、一般礦井 $1/秒、中立礦井 $2/秒、挖一格土 $2、金礦脈 $15、大寶藏 $80 |
| 礦工動作 | 走一格 0.3 秒、挖一格 0.8 秒（硬土 3 倍）、插火把 0.4 秒、用道具 0.8 秒 |
| 挖掘屬於哪個狀態 | 算在「移動」裡：往目標走的路上遇到土就挖 |
| 礦工升級 | Lv2 $60、Lv3 $120；每級挖得更快、走得更快、血量 +1（3/4/5） |
| 擊殺 | 相鄰的敵對礦工自動互打，每 0.6 秒 1 點傷害；被擊殺回泉水蹲 12 秒，手上道具和增幅消失 |
| 賣礦工 | 拿回 $40 + 升級花費的一半 |
| 視野 | 礦工：曼哈頓距離 ≤ 2（暫時）；火把：九宮格；家：曼哈頓距離 ≤ 5 |
| 視野佔比 | 火把與家照亮的格數，兩隊相比 |
| 佔領 | 礦井站 3 秒、大寶藏站 8 秒（兩隊都在就不算） |
| 礦井 | 三座中立礦井的位置開局就標在地圖上；對手開局自帶的那一座離他的家很近，要親眼看到才知道 |
| 大寶藏 | 位置一開始就公開；搶到得 $80，並在自己這一側隨機多一個假的家 |
| 情報 | 概略情報 $50（標出一個 11×11 的範圍）、精確情報 $200（直接標出敵方的家） |
| 炸彈 | $150，同時只能一顆；攜帶者移動與挖掘慢 1.6 倍、不能打架 |
| 公告 | 4:00 公告視野佔比；5:00 結算 |

道具效果與價格寫在商店裡（滑鼠移上去看說明）。洞穴是開局就挖空的空間，沒有特殊效果。

## 專案結構

```
index.html, style.css     網頁本體與樣式
server.js, start.bat      遊戲伺服器與一鍵啟動
src/version.js            版本號
src/sim/                  遊戲規則（不碰畫面，瀏覽器和伺服器共用）
  constants.js            規則數值
  items.js                商店道具
  chars.js                角色與加成
  mapgen.js               地圖生成
  path.js                 找路
  game.js                 模擬核心：指令進、狀態與事件出
  view.js                 玩家視角（只留某一隊看得到的東西）與連線用的差異編碼
src/ai/bot.js             電腦對手（三種難度）
src/server/               伺服器端
  ws.js                   WebSocket（自己實作，不依賴套件）
  lobby.js                大廳、房間、對局、斷線重連
  accounts.js             帳號與戰績
src/client/               玩家端
  main.js                 進入點：單機、連線、選單背景示範
  pixels.js               像素圖資料：礦工、家、道具圖示、地形與裝飾（16×16 點陣，用文字描述）
  sprites.js              把像素圖資料變成可以畫的圖並快取
  render.js               畫面：整數倍放大的像素風、地圖細節、迷霧、範圍預覽、小地圖
  ui.js                   對局中的介面
  menu.js                 主選單、大廳、房間、帳號
  net.js                  連線與自動重連
  audio.js                音效與音樂（即時合成，沒有音檔）
test/                     自動測試
```

網頁版沒有「更新包」：每次打開都是從伺服器拿最新的程式；分頁開著的時候伺服器更新了，重新連線時會自動重新整理。
